# Олександрійський ліцей інформаційних технологій

Сучасний веб-сайт для Олександрійського ліцею інформаційних технологій, побудований з використанням найновіших технологій.

## 🚀 Стек технологій

### Основне ядро
- **Next.js 15** (App Router) - React фреймворк з Server Actions
- **TypeScript** - Типізація та безпека коду
- **React 19** - UI бібліотека

### База даних
- **SQLite** - Локальна база даних (файл `local.db`)
- **Turso (libSQL)** - Опціонально для хмарного хостингу
- **Drizzle ORM** - Легка та швидка ORM
- **Drizzle Kit** - Інструменти для міграцій та Drizzle Studio

### Інтерфейс та UI
- **Tailwind CSS** - Utility-first CSS фреймворк
- **shadcn/ui** - Готові компоненти (Button, Card, Dialog, Table, Form, Select, Badge тощо)
- **Lucide React** - Іконки
- **Radix UI** - Headless UI компоненти
- **Sonner** - Toast notifications
- **AutoAnimate** - Плавні анімації списків

### Утіліти та інші
- **React Hook Form** - Управління формами
- **Zod** - Валідація даних
- **bcryptjs** - Хешування паролів
- **jose** - JWT токени для аутентифікації

## 📦 Встановлення

1. Клонуйте репозиторій:
```bash
git clone <repository-url>
cd object-24_LIT
```

2. Встановіть залежності:
```bash
npm install
```

3. Налаштуйте змінні середовища:
```bash
cp .env.example .env
```

4. Створіть базу даних:
```bash
npm run db:push
```

5. Заповніть базу тестовими даними:
```bash
npm run db:seed
```

6. Запустіть dev сервер:
```bash
npm run dev
```

Сайт буде доступний за адресою `http://localhost:3000`

## 🔐 Адмін панель

Адмін панель доступна за адресою `/admin`

**Тестові дані для входу:**
- Email: `admin@lit.kr.ua`
- Пароль: `admin123`

**ВАЖЛИВО:** Змініть дані адміністратора в `.env` файлі перед деплоєм у продакшн!

### Можливості адмін панелі:
- ✅ Управління вчителями (CRUD: створення, редагування, видалення)
- ✅ Управління профілями навчання (CRUD з категоріями та кольорами)
- ✅ Управління відгуками випускників (CRUD з публікацією/приховуванням)
- ✅ Управління новинами та оголошеннями (CRUD з категоріями та статусами)
- ✅ Статистика та аналітика на Dashboard
- ✅ Сучасний інтерфейс з таблицями, формами та модальними вікнами
- ✅ Toast notifications для успішних та помилкових операцій
- ✅ Валідація форм з детальними повідомленнями про помилки

## 🌐 Розділи сайту

### Публічні сторінки
- **Головна** - Hero секція, огляд профілів, останні новини та відгуки
- **Профілі навчання** - Список всіх профілів + детальна сторінка кожного профілю
  - Математично-інформаційний
  - Українська філологія
  - Біолого-хімічний
  - Історичний
- **Вчителі** - Інформація про педагогічний склад з фото та контактами
- **Відгуки** - Історії успіху випускників з університетами та досягненнями
- **Новини** - Список новин + детальна сторінка кожної новини
- **Про нас** - Місія, цінності та переваги ліцею

### Адмін панель
- **Dashboard** - Статистика та швидкі дії
- **Управління контентом** - CRUD операції для всіх розділів
